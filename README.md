# Kamino Finance - Deep Integration Documentation

## Overview
This document outlines how the **Kamino Predict Vault** integrates with Kamino Finance's infrastructure. Our implementation goes beyond a simple frontend display by utilizing a custom Solana Smart Contract (written in Rust/Anchor) that natively interacts with the Klend (Kamino Lending) program via Cross-Program Invocation (CPI).

## Technical Implementation (CPI)

Instead of relying on frontend SDKs for core logic, we embedded the integration at the program level to ensure trustless execution and true onchain risk management.

### 1. Risk-Adjusted Allocation
When a user deposits USDC into our Vault, the program splits the capital according to an 80/20 risk profile:
- **80% (Principal):** Programmatically routed to the Kamino Lending Reserve.
- **20% (Risk Capital):** Held in a dedicated PDA for prediction market execution.

### 2. Kamino Lending Interaction
The core interaction happens in our `harvest_and_predict` instruction. The Vault acts as an automated director:

- **Accounts Required:** The instruction natively requires Kamino's official accounts:
  - `klend_program`
  - `kamino_reserve`
  - `kamino_lending_market`
  - `reserve_liquidity_supply`

- **Execution Flow:** The Vault's PDA signs a CPI transaction directed to the `klend_program`. It verifies the accrued yield on the deposited principal. If the total balance exceeds the initial user deposits, the contract mathematically isolates the profit (Yield) and extracts it.

### 3. Yield as the Strategy Engine
The yield generated from Kamino is not just displayed; it is the *engine* of the dApp. The extracted yield from Kamino is automatically transferred to the prediction pool, allowing users to participate in directional bets using strictly the house money (yield), while Kamino secures the baseline principal.

## Why this meets the "Deep Integration" criteria
- **Core Engine:** Kamino is the foundational layer of our product. Without the yield generated by Klend, the risk-free prediction strategy mathematically fails.
- **Program-Level Logic:** The integration is secured via Rust CPIs using Anchor, rather than off-chain scripts.
- **Advanced DeFi Strategy:** We abstracted a complex, multi-step position management strategy (Deposit -> Farm Yield -> Extract Yield -> Bet) into a single user action.
